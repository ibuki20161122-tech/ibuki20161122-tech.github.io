FEATURES

なぜ CraftForge なのか

🖥
フル GUI

コマンドラインは不要。すべての操作をグラフィカルなインターフェースで完結できます。

🔌
プラグイン管理

PaperMC公式サイト Hangar から検索・ワンクリックインストール。plugins フォルダも直接開けます。

🧩
MOD 管理

Modrinth API 連携でFabric・ForgeのMODを検索・インストール。バージョン自動絞り込み対応。

☕
Java 自動 DL

Javaが未インストールでも自動でダウンロード＆セットアップ。面倒な環境構築が不要です。

⚙
設定エディタ

server.properties をGUIで編集・保存。難しいファイル編集なしに設定を変更できます。

💻
コンソール内蔵

サーバーの起動・停止・コマンド入力がアプリ内のコンソールから直接できます。
